# Getting help

Check the [README](README.md), [release notes](https://github.com/felixpy/envark/releases), and [existing issues](https://github.com/felixpy/envark/issues) first.

- **Something is broken:** submit a [bug report](https://github.com/felixpy/envark/issues/new?template=bug_report.yml) with a minimal reproduction.
- **A tool or workflow is missing:** submit a [feature request](https://github.com/felixpy/envark/issues/new?template=feature_request.yml) explaining the problem and the tool manager involved.
- **You have a usage question:** open an [issue](https://github.com/felixpy/envark/issues/new) and describe what you are trying to achieve. Maintainers can apply the `question` label.
- **You found a vulnerability:** report it privately as described in [SECURITY.md](SECURITY.md).

GitHub Issues is the public entry point. You do not need a Linear account to report an issue or contribute.

Before sharing logs or screenshots, remove access tokens, private repository names, configuration secrets, and personal paths. Support is provided by volunteers without a guaranteed response time.
